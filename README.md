Parking Patience.

Do you have the patience to park your car?

This is a mini stleath bidding game, where you your patience for the scenario of parking gets tested and you have to bid for the number of seconds, so that you can potentially outwait your opponent.

Features:
1) it has 8 rounds with mystery players that generate bidding against you.
2) there is a patience meter that drains every bid or increases if you outwait someone else.
3) a bgm track looped for someone sweet ambient music sumn like an engine hum, which is generated by the Web Audio API.

How to run it locally?
1) Download this repo and open index.html in your browser.

How does it work?/ How to play?:

You'll start the game by any amount of seconds you wanna wait for depending upon the scenario given there, you basically can't match the same amount of seconds you wait w anyone else.
Each round you'll have to outwait everyone w/o matching time w anyone which increases your patience bar. 
All the audio from the click, the honks, the winning/losing chime sounds, bgm loop is from Web Audio Api so you dont need to really get an external mp3 or mp4 files.
